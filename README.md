# GNOME Calculator [![Build Status](https://gitlab.gnome.org/GNOME/gnome-calculator/badges/master/build.svg)](https://gitlab.gnome.org/GNOME/gnome-calculator/pipelines)

Calculator is an application that solves mathematical equations and is suitable as a default application in a Desktop environment.

[![Download on Flathub](https://upload.wikimedia.org/wikipedia/commons/thumb/a/a6/Flathub-badge-en.svg/240px-Flathub-badge-en.svg.png)](https://flathub.org/apps/details/org.gnome.Calculator)

## Date calculations

Open **Date Calculation** in the primary menu. Compare two dates to see the
elapsed days and leap-day count, or add/subtract a whole number of days from a
start date. Dates use `YYYY-MM-DD`, from `0001-01-01` through `9999-12-31`.
The elapsed value is end minus start; leap days are counted from the earlier
date up to, but excluding, the later date. Signed day offsets are supported.
Invalid input and results outside the supported range show an error.
See the built-in [date-calculation help](help/C/dates.page) for examples.
